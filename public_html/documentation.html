User Documentation

Introduction

This is a contact management Application, which allows users to create, read, update and delete contacts.

Users from all demographic will have no problem navigating and utilizing this tool

This is a user documentation for the contact management application

This documentation will provide a step-by-step guide on how to use the application

It will also provide a list of all the features and functionality of the application

It also provides a table of content for easy navigation

Getting Started

Adding a new Contact

  • Click on the "Add Contact" button on the top of the page
  • Fill in the form with the contact's information
  • Endeavor to fill all the fields else you won't be able to save the contact
  • Click on the "Add Contact" button to save the contact information

Updating Contact Details

This can be done in two different ways

  • Click on the "Edit" icon on the contact you want to update
  • Update the contact's information
  • Click the "OK" button to save the contact details

OR

  • Click on the "Update Contact" button on the top of the page
  • Provide the email of the user contact you wish to update
  • Click the "Update contact" button to save your changes

Deleting a Contact

This can be done in two different ways

  • Click on the "Delete" icon on the contact you want to delete
  • Click the "OK" button to confirm the deletion

OR

  • Click on the "Delete Contact" button on the top of the page
  • Provide the email of the user contact you wish to delete
  • Click the "Delete contact" button to confirm the deletion

Features and Functionality

Features

All contacts saved is displayed once the page is loaded

  • Users can add new contacts
  • Users can update existing contacts
  • Users can delete existing contacts

Functionality

Contact update fuctionality can be accessed in two different ways

  • Users can edit a specific user's contact information by using the "update contact" button on the top of the page and providing the email of the user contact they wish to update
  • Users can also go through the contact informations displayed and click on a specific contact's edit icon to update it

Contact deletion fuctionality can be accessed in two different ways

  • Users can delete a specific user's contact information by using the "delete contact" button on the top of the page and providing the email of the user contact they wish to delete
  • Users can also go through the contact informations displayed and click on a specific contact's trash icon to delete it
